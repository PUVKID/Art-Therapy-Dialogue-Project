## 프로젝트 소개

YOLO 객체 탐지와 GPT-4o-mini의 텍스트 생성을 Gradio 화면·보고서에 연결합니다. 논문 설계와 공개 앱의 실제 두 호출, 점수 시각화 노트북은 구분해야 합니다. 객체 요약이 언어 모델에 전달되는 범위를 먼저 읽습니다.

### LEVEL 2 · 합성 자료와 학습 횟수

| 대상·조건 | 동작과 의미 |
| --- | --- |

30 단계 코드에서 재개 플래그가 학습 호출로 전달되지 않는다는 차이 때문에 원고의 누적 학습을 그대로 구현했다고 볼 수 없습니다.

### LEVEL 2 · 손실과 탐지 지표

| 구분 | 지표 | 원고 보고값 |
| --- | --- | ---: |
| 손실 | box loss | 0.38 |
| 손실 | classification loss | 0.28 |
| 손실 | DFL | 0.81 |
| 탐지 지표 | mAP50 | 0.92 |
| 탐지 지표 | mAP50–95 | 0.78 |

**평가 조건:** 학습·검증 자료가 같습니다.

box·classification·DFL은 서로 다른 학습 목적의 손실이고 mAP는 평가 지표입니다.

mAP50의 겹침 기준과 mAP50 –95의 여러 겹 침 기준을 구분해야 0.92와 0.78의 차이를 읽을 수 있습니다.

검증 자료가 독립적이지 않으므로 모델의 적합도와 외부 일반화 성능을 분리합니다.

### LEVEL 2 · 평가 배열과 기술통계

각 평가 배열은 **32개**입니다.

| 평가 항목 | 3점 개수 | 4점 개수 | 5점 개수 |
| --- | ---: | ---: | ---: |
| 정서 적절성 | 2 | 10 | 20 |
| 자연스러움 | 1 | 5 | 26 |
| 공감 | 2 | 12 | 18 |

**기술통계:** 평균·중앙값·표준 편차 ddof =1·25/75 분위수.

항목별로 같은 32개라는 길이와 서로 다른 3·4·5점 빈도를 함께 봅니다.

평균이 비슷해도 분포가 다를 수 있으므로 중앙값·표본 표준 편차·사분위수를 같이 계산합니다.

이 코드 입력과 개인별 응답 기록의 연결은 제공되지 않아 실제 응답 수집의 검증을 대신하지 못합니다.

| 그림 입력·분석 | 그림 분석은 10~15 문장 요청. |
| 독립 질문 요청 | ask_gpt는 입력 질문만 별도 전송. |
| API 요청·실패 | API 예외는 오류 문자열로 반환, 그림 분석은 이어서 PDF 생성을 시도합니다. |

언어모델 호출과 보고서 생성이 한 함수에 이어져 있어 API 실패가 곧 보고서 단계 중단을 뜻하지 않습니다.

텍스트 질문 경로에는 앞선 대화 이력을 추가하지 않습니다.

상담형 문장 생성과 임상 상담의 유효성 검증은 별개의 문제입니다.

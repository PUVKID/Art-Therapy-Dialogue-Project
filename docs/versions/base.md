## 🧩 주요 내용

- 이미지를 올려 객체 탐지 결과를 확인하고 분석 호출을 수행합니다. 텍스트 질문 호출과 그림 분석 호출은 별도 경로입니다.
- 4차 점수 시각화와 달리 사용자가 입력하는 그림·대화의 처리를 담당합니다.

## 🔄 자료 구성

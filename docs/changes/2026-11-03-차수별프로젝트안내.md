# 🧭 차수별 프로젝트 안내

차수마다 목적·처리 흐름·파일 구성·환경과 사용 순서·결과 해석을 나누어 설명했습니다. 원고와 실행 코드, 실험 결과와 발표 자료의 역할을 연결하고 작은 설정 차이와 알려진 문제를 함께 적었습니다.

- 첫 화면과 전체 목차에서 모든 실제 단계의 폴더·독립 설명·직전 전체 비교로 이동할 수 있습니다.
- 긴 파일 기록과 바이너리 해시 표는 상세 페이지 아래에서 펼쳐 볼 수 있습니다.
- 기존 코드·데이터·그래프·논문 및 첨부 파일은 그대로 사용합니다.
